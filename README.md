# Fake GPS

Расширение для Chromium-браузеров, которое подменяет Browser Geolocation API и позволяет быстро переключаться между сохранёнными локациями.

![Fake GPS](files/screen.png)

## Возможности

- включение и отключение подмены геолокации;
- несколько сохранённых локаций и быстрое переключение между ними;
- выбор точки на карте;
- поиск места по названию;
- ручной ввод широты и долготы;
- редактирование и удаление локаций;
- светлая и тёмная темы;
- русский и английский интерфейс.

## Установка

1. Откройте `chrome://extensions/` или `edge://extensions/`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку расширения.

Для добавления новой точки нажмите **Добавить локацию**, выберите место на карте и нажмите **Применить**. Клик по сохранённой локации активирует её, а клик по уже активной — отключает подмену.

## Как работает

Fake GPS подменяет `navigator.geolocation.getCurrentPosition()` и `navigator.geolocation.watchPosition()`. Для Google-запросов также используется GEO-заголовок с выбранными координатами.

Карта работает на OpenStreetMap, поиск и определение названия точки — через Nominatim.

> Подмена геолокации не меняет IP-адрес. Сайты, определяющие местоположение по IP, данным аккаунта или другим сигналам, могут показывать другое местоположение.

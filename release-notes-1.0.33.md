# Fake GPS v1.0.33

Первый подготовленный релиз Fake GPS — расширения для Chromium-браузеров, которое позволяет подменять Browser Geolocation API и быстро переключаться между сохранёнными локациями.

## Основное

- включение и отключение подмены геолокации;
- несколько сохранённых локаций и быстрое переключение между ними;
- выбор точки на OpenStreetMap;
- поиск места по названию через Nominatim;
- ручной ввод широты и долготы;
- редактирование и удаление сохранённых локаций;
- отображение выбранной точки фирменным маркером;
- светлая и тёмная темы;
- русский и английский интерфейс;
- отдельные статусные иконки включённой и выключенной подмены;
- GEO-заголовок для Google-запросов.

## Интерфейс

В релизе доработан popup расширения: активную локацию можно включать и выключать кликом по её блоку, активная сохранённая точка отмечается красным крестиком, а элементы списка имеют более аккуратные отступы.

Окно выбора локации поддерживает поиск, ручной ввод координат, масштабирование колесом мыши и сразу показывает сохранённый маркер при редактировании существующей точки.

## Установка

1. Распакуйте архив.
2. Откройте `chrome://extensions/` или `edge://extensions/`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку.

> Fake GPS не меняет IP-адрес. Сайты, определяющие местоположение по IP или другим сигналам, могут показывать другое местоположение.
